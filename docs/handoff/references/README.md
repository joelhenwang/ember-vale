# Visual references

Existing Ember Vale pages/components are the primary frontend baseline. These images provide context for missing gameplay/details and specific editor behavior. Do not replace existing pages merely to match incidental differences in the images.

- `world-preset-details.png`: map/places alongside setting overview and use/edit actions.
- `live-character-details.png`: observatory context, small profile, full-body image, current activity/equipment/physical state/history.
- `character-profile-full-body.png`: profile approval precedes reference-conditioned full-body generation; both displayed in the preview panel.
- `world-editor-places.png`: structured place/appearance form plus environmental preview.
- `character-editor-voice.png`: personality/voice questions and attributed dialogue preview.

Artwork, sample counts, equipment/injuries, extra characters, displayed lore and status badges are illustrative. They do not define seed data or prove provider capability. Use clean standalone art; never crop a UI screenshot into a production portrait or world cover with its text/buttons still visible.
